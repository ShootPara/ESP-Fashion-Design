### First 14-week module: **Studio English Foundations I**

This module maps to the first-semester UEG Fashion Design foundation courses: drawing, introductory sewing, introductory patternmaking, design studies, creativity lab, and text production. UEG’s matrix lists those first-semester courses under the 2021/1 curriculum for the bachelor’s degree in Design de Moda, with the full course carrying 2,580 hours over a minimum of 4 years. ([Universidade Estadual de Goiás](https://www.ueg.br/exec/consulta_diretoria/?cur=91&funcao=modal_matriz&mod=1&variavel=38&utm_source=chatgpt.com "::.Universidade Estadual de Goiás.::"))

The module should fit cleanly into our pack model: **Module → Level → Week → Task(s) + Practice item(s)**, using the core categories Listening, Reading, Writing, Practice, Performance, and teacher-observed Speaking. The project requirements already support weekly organization, reusable task definitions, placements, practice items, audio/image assets, rubrics, and feedback workflows.

## Table of contents: 14-week module

|Week|Unit title|Core activities|Activity types|Expected outcomes|Expected duration|
|--:|---|---|---|---|--:|
|1|**Welcome to Fashion Design English**|placement check; fashion student profile; basic course words; first correction routine|diagnostic practice; visual vocabulary; guided writing; correction card review|Student can introduce themselves as a fashion design student and understand the weekly app routine|60–75 min app + 45–60 min teacher session|
|2|**The Fashion Studio**|identify studio spaces, tools, and classroom actions; listen to simple studio instructions|listen and choose; image vocabulary cards; visual scavenger hunt; guided sentences|Student can recognize and write basic studio/tool vocabulary: scissors, needle, thread, fabric, sketchbook, mannequin, ruler|70–90 min app + 45–60 min teacher session|
|3|**Garments and Categories**|match garment names to images; read short product descriptions; write simple garment sentences|image-to-text match; short reading; phrase frames; guided sentence build|Student can name common garments and describe them with _This is / It has / It is_|70–90 min app + 45–60 min teacher session|
|4|**Parts of a Garment**|label garment parts; listen and identify parts; complete garment-description phrases|listen and label; picture vocabulary; fill-the-phrase; short description|Student can identify and use words like sleeve, collar, hem, seam, zipper, button, pocket, waistband|70–90 min app + 45–60 min teacher session|
|5|**Body, Figure, and Observation Drawing**|label basic body/figure terms; read sketch captions; write a short figure/sketch description|visual reading; vocabulary bridge PT–EN; caption builder; guided writing|Student can describe a fashion figure or sketch using simple body, pose, and proportion language|70–90 min app + 45–60 min teacher session|
|6|**Color, Shape, and Line**|classify colors and shapes; compare simple silhouettes; describe a look visually|visual scavenger hunt; compare two looks; phrase frames; short writing|Student can describe visual elements: color, shape, line, long/short, wide/narrow, fitted/loose|75–90 min app + 45–60 min teacher session|
|7|**Fabric and Texture Basics**|match fabrics/textures to images; listen to fabric descriptions; write a fabric comparison|listen and choose; image vocabulary; compare two swatches; guided writing|Student can describe basic material qualities: soft, rough, smooth, shiny, light, heavy, transparent, stretchy|75–90 min app + 45–60 min teacher session|
|8|**Sewing Actions**|sequence basic sewing steps; read a short process; practice action verbs|listen and sequence; process reading; verb drill; process note|Student can understand and write simple process language: cut, fold, pin, sew, stitch, press, measure|75–90 min app + 45–60 min teacher session|
|9|**Introduction to Patternmaking English**|identify simple pattern pieces and measurements; read a measurement note; write simple instructions|listen and label; visual reading; vocabulary bridge; guided instruction writing|Student can understand basic patternmaking language: pattern, piece, measurement, waist, bust, length, width|75–90 min app + 45–60 min teacher session|
|10|**Describing a Sketch**|read model sketch descriptions; match captions; write a description of a sketch|image-to-text match; caption builder; short description; correction review|Student can write a clear 70–100 word description of a garment sketch|80–95 min app + 45–60 min teacher session|
|11|**Design Details**|identify closures, trims, details, and decorative elements; write detail-focused captions|visual scavenger hunt; picture vocabulary; phrase frames; caption set|Student can describe visible design details: zipper, buttons, pleats, ruffles, pockets, stitching, print|75–90 min app + 45–60 min teacher session|
|12|**Creative Inspiration**|read a simple inspiration note; listen to a mini design brief; write a design rationale|audio brief check; short reading; phrase frames; design rationale writing|Student can explain a simple design choice using _because_, _for_, _inspired by_, and _I chose_|80–100 min app + 45–60 min teacher session|
|13|**Giving Simple Design Feedback**|practice critique phrases; read peer comments; revise a description after feedback|reusable critique phrases; model answer comparison; targeted revision; short response|Student can give simple constructive feedback: _I like…_, _The color works because…_, _You could…_|75–90 min app + 45–60 min teacher session|
|14|**Mini Design Board**|assemble final English artifact: image labels, garment description, fabric/detail notes, short rationale|performance task; writing portfolio artifact; correction review; teacher-observed presentation|Student completes a reusable mini portfolio page and can explain it briefly in the teacher session|90–120 min app + 45–60 min teacher session|

## Module artifact progression

|Stage|Weeks|Student artifact|
|---|--:|---|
|Foundation vocabulary|1–4|personal fashion profile + labeled garment|
|Visual description|5–7|sketch/figure description + fabric description|
|Studio process|8–9|simple sewing or patternmaking process note|
|Applied description|10–12|garment sketch description + design rationale|
|Integration|13–14|mini design board with corrected English captions and short explanation|

## End-of-module outcome

By the end of Week 14, the student should be able to produce a simple but useful English design artifact:

| Component                | Expected student output                                  |
| ------------------------ | -------------------------------------------------------- |
| Image labels             | 8–12 garment, fabric, or design-detail labels            |
| Garment description      | 80–120 words                                             |
| Fabric/detail note       | 3–5 short sentences                                      |
| Design rationale         | 4–6 short sentences explaining inspiration and choices   |
| Teacher-session speaking | 45–90 second guided explanation of the mini design board |
