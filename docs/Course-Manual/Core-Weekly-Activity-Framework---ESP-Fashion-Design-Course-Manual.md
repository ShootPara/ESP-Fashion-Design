## Core weekly activity scaffold

|Weekly component|Activity type|Routine student action|Fashion-design use case|Platform task type|Feedback style|
|---|---|---|---|---|---|
|Listening|**Listen and Choose**|Listen to short audio and choose the correct image, term, or answer|Identify a garment, fabric, tool, sketch, or styling choice from audio|`listening`|auto-scored|
|Listening|**Listen and Sequence**|Put steps in the correct order|Sewing steps, patternmaking steps, photoshoot setup, collection workflow|`listening`|auto-scored|
|Listening|**Listen and Label**|Listen and tap/choose labels on an image|Label sleeve, hem, collar, zipper, waistband, seam, pocket|`listening`|auto-scored|
|Listening|**Phrase Catch**|Fill in missing words from a short audio|“The dress is made of cotton”; “Pin the fabric before sewing”|`listening` / `practice`|auto-scored|
|Listening|**Audio Brief Check**|Listen to a mini client/teacher brief and answer questions|Target customer, occasion, color palette, fabric request|`listening`|auto-scored|
|Listening|**Micro Lecture**|Listen to a 60–90 second explanation and answer gist/detail questions|fashion history, sustainability, textile properties, CAD, retail|`listening`|auto-scored + transcript after attempt|

## Reading / visual reading activity scaffold

|Weekly component|Activity type|Routine student action|Fashion-design use case|Platform task type|Feedback style|
|---|---|---|---|---|---|
|Reading / visual reading|**Image-to-Text Match**|Match descriptions to images|Match looks, silhouettes, fabric swatches, accessories, retail displays|`reading`|auto-scored|

|Reading / visual reading|**Short Text + Questions**|Read 100–180 words and answer comprehension questions|designer profile, trend blurb, fashion history note, sustainability note|`reading`|auto-scored|
|Reading / visual reading|**Caption Builder Reading**|Read captions and choose the best one for an image|portfolio captions, moodboard captions, collection labels|`reading` / `practice`|auto-scored|
|Reading / visual reading|**Compare Two Looks**|Read two descriptions and answer comparison questions|“Which look is more formal?” “Which fabric is lighter?”|`reading`|auto-scored|
|Reading / visual reading|**Process Reading**|Read a short procedure and identify the sequence/purpose|sewing, moulage, prototyping, merchandising setup|`reading`|auto-scored|
|Reading / visual reading|**Mini Research Note**|Read a simplified academic/professional note and extract key information|TCC prep, fashion history, sustainability, consumer behavior|`reading`|auto-scored + short written response|

## Writing task scaffold

|Weekly component|Activity type|Routine student action|Fashion-design use case|Platform task type|Feedback style|
|---|---|---|---|---|---|

|Writing|**Caption Set**|Write 3–5 short captions|portfolio image captions, moodboard captions, process captions|`writing`|AI/auto feedback|
|Writing|**Process Note**|Explain steps using sequence words|sewing process, prototype process, styling workflow, event setup|`writing`|AI/auto feedback|
|Writing|**Design Rationale**|Explain a design choice using because / so / for|fabric choice, color palette, silhouette, target customer|`writing`|AI/auto feedback + rubric|
|Writing|**Professional Message**|Write a short email/message|internship email, teacher question, client clarification, team update|`writing`|AI/auto feedback|
|Writing|**Mini Portfolio Artifact**|Produce a polished reusable text|collection concept, product description, artist statement, TCC abstract|`writing` / `performance`|teacher review + rubric|

## Auto-feedback / correction review scaffold

|Weekly component|Activity type|Routine student action|Fashion-design use case|Platform task type|Feedback style|
|---|---|---|---|---|---|
|Auto-feedback / correction|**Correction Card Review**|Review marked errors and corrections|vocabulary, grammar, word order, missing articles, spelling|`practice`|automated|
|Auto-feedback / correction|**Try Again: Targeted Revision**|Revise one answer after feedback|improve garment description or caption|`writing` / `practice`|automated + saved revision|
|Auto-feedback / correction|**Error Pattern Mini-Drill**|Practice the student’s repeated issue|adjective order, plural nouns, “made of,” past tense, comparatives|`practice`|auto-scored|
|Auto-feedback / correction|**Model Answer Comparison**|Compare own answer to a simple model|product description, process note, collection concept|`practice`|guided self-check|
|Auto-feedback / correction|**Vocabulary Upgrade**|Replace vague words with field terms|“nice fabric” → “lightweight cotton”; “thing” → “zipper/closure”|`practice`|auto-scored|
|Auto-feedback / correction|**Revision Log**|Confirm what changed in the final version|portfolio caption, weekly paragraph, design rationale|`practice`|completion + teacher visibility|

## Teacher-led session scaffold

|Weekly component|Activity type|Routine teacher/student action|Fashion-design use case|Platform support|Feedback style|
|---|---|---|---|---|---|
|Teacher-led session|**Progress Check**|Teacher reviews completion, scores, and stuck points|keep students moving through the module|dashboard / grades|teacher feedback|
|Teacher-led session|**Pronunciation Clinic**|Practice 8–12 key terms from the week|fabric, garment, sewing, styling, retail, TCC vocabulary|task review + word list|live correction|
|Teacher-led session|**Show and Tell**|Student explains one image/sketch/design in simple English|sketch, accessory, moodboard, prototype, portfolio image|optional speaking/performance task|teacher feedback|
|Teacher-led session|**Guided Correction**|Teacher reviews common class errors|recurring grammar/vocabulary issues from app submissions|analytics / correction log|live explanation|
|Teacher-led session|**Mini Critique Circle**|Students give short structured feedback|“I like…” “You could…” “The fabric works because…”|speaking/performance placement|live peer + teacher feedback|
|Teacher-led session|**Portfolio Polish**|Teacher helps improve one reusable student artifact|caption, concept paragraph, product description, TCC abstract|writing submission review|teacher rubric/comment|
|Teacher-led session|**Speaking Rehearsal**|Students practice one short spoken output|30–90 second design explanation|optional audio/speaking task|live coaching|

The LMS requirements already support this split: students complete assigned tasks, access practice content, review grades/feedback, and message the teacher; teachers manage tasks, assignments, grading, feedback, redo permissions, messages, and progress.

## Recommended weekly pattern

|Order|Time|Activity slot|Best routine mix|
|--:|--:|---|---|
|1|5 min|Weekly opener|visual prompt + 6–10 key terms|
|2|10–15 min|Listening|one listening activity from the listening bank|
|3|10–20 min|Reading / visual reading|one image/text-based comprehension activity|
|4|10–15 min|Vocabulary / phrases|one fast practice set, preferably mobile-friendly|
|5|15–30 min|Writing|one applied fashion-design output|
|6|5–10 min|Correction review|revise, compare, or complete targeted mini-drill|
|7|45–60 min|Teacher-led session|progress check + pronunciation + one short speaking/performance activity|
