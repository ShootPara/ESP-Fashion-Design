# Module 1 — Week 7 Detailed Breakdown

## Week 7 title

**Fabric and Texture Basics**

## Position in module

|Field|Value|
|---|---|
|Module|Studio English Foundations I|
|Week|7 of 14|
|Student level|A2 English|
|Main university-course connection|Introductory sewing, introductory design studies, creativity lab, garment observation|
|Main ESP function|Describing fabrics, textures, simple material qualities, and appropriate uses|
|Main student artifact|Fabric Swatch Description Card|
|App workload|75–90 minutes|
|Teacher-led session|45–60 minutes|

## Week 7 purpose

Week 7 introduces the English students need to talk about **materials**. Up to this point, students have described garments, garment parts, sketches, figures, colors, shapes, and lines. Now they add fabric and texture language: what a garment is made of, how a material looks, how it feels, and what it is useful for.

This week supports early sewing and design coursework because fabric choice affects silhouette, comfort, construction, movement, and final appearance. The online platform can use high-quality fabric swatch photos, garment photos, short product-style descriptions, and simple audio descriptions.

The main output is a **Fabric Swatch Description Card**: the student describes one fabric or fabric-like visual sample using color, texture, weight, stretch, opacity, and possible use.

# Main grammar / phrase targets

|Function|Sentence frames|
|---|---|
|Naming fabric|This is cotton. / This is denim.|
|Naming a swatch|This is a fabric swatch.|
|Saying material|It is made of cotton. / The jacket is made of denim.|
|Describing feel|It feels soft. / It feels rough.|
|Describing appearance|It looks shiny. / It looks matte.|
|Describing weight|It is lightweight. / It is heavy.|
|Describing structure|It is stretchy. / It is stiff. / It is flowy.|
|Describing use|It is good for summer dresses.|
|Possible use|It can be used for skirts, shirts, or dresses.|
|Preference|I like this fabric because it is soft and light.|

## Language notes for Codex

|Language point|Instructional note|
|---|---|
|“made of”|Main material phrase: “The shirt is made of cotton.”|
|“feels”|Use for touch/texture qualities: soft, rough, smooth, heavy, light|
|“looks”|Use for visual qualities: shiny, matte, transparent, textured|
|“good for”|Use for purpose/appropriateness: “good for summer,” “good for jackets”|
|“can be used for”|Slightly more advanced but very useful for design reasoning|
|adjective placement|“a soft cotton fabric,” “a heavy denim jacket,” “a shiny silk blouse”|
|fabric nouns|Some fabric names are uncountable in simple use: “This is cotton,” not “a cotton”|
|swatch/sample|Countable: “This is a fabric swatch,” “These are fabric samples”|

# Activity 7 — Fabric Swatch Description Card

|Field|Specification|
|---|---|
|Activity purpose|Produce the main Week 7 written artifact|
|Activity type|Guided writing|
|Platform category|`writing`|
|Estimated time|15–25 minutes|
|Submission mode|`text_response`|
|Feedback|hybrid: automated correction suggestions + teacher visibility|
|Target length|70–100 words|
|Required assets|student-selected fabric swatch or teacher-provided fabric image|
|Student-facing language|Portuguese instructions; English sentence frames|

## Writing prompt

**Portuguese student instruction:**

> Escolha uma amostra de tecido da galeria. Escreva uma descrição em inglês. Descreva o tipo de tecido, a cor, a textura, o peso, a aparência e para que tipo de peça ele poderia ser usado.

## Required content

|Required element|Sentence frame|
|---|---|
|fabric name|This is ___. / This is a ___ fabric swatch.|
|color|It is ___.|
|texture|It feels ___.|
|appearance|It looks ___.|
|weight/structure|It is lightweight/heavy/stretchy/stiff/flowy/structured.|
|possible use|It is good for ___. / It can be used for ___.|
|preference|I like this fabric because ___.|

## Model answer 1 — cotton

> This is a cotton fabric swatch. It is white and lightweight. It feels soft and smooth. It looks simple and clean. It is breathable and comfortable. It is good for shirts, blouses, and summer dresses. I like this fabric because it is practical and easy to use.

## Model answer 2 — denim

> This is denim. It is blue, heavy, and structured. It feels thick and strong. It looks casual and classic. Denim is good for jeans, jackets, skirts, and bags. I like this fabric because it is strong and useful for everyday garments.

## Model answer 3 — lace

> This is black lace. It is textured and sheer. It looks decorative and elegant. It is lightweight, but it is not plain. It can be used for sleeves, details, dresses, and accessories. I like this fabric because it makes a garment more interesting.

## Feedback targets

|Priority|Feedback focus|
|---|---|
|1|correct fabric/material vocabulary|
|2|correct use of “made of” when describing garments|
|3|correct use of “feels” for touch qualities|
|4|correct use of “looks” for visual qualities|
|5|clear use of “good for” or “can be used for”|
|6|adjective order: soft cotton fabric, heavy blue denim|
|7|sentence boundaries and capitalization|
|8|spelling of fabric and texture vocabulary|

# Week 7 course-manual text summary

**Week 7 introduces fabric and texture language for fashion design students. Students learn common fabric/material names such as cotton, denim, linen, silk, wool, polyester, knit fabric, woven fabric, lace, and leather. They also learn adjectives for texture, surface, weight, movement, structure, and visibility, including soft, rough, smooth, shiny, matte, lightweight, heavy, stretchy, stiff, flowy, structured, sheer, and opaque. The online work includes fabric vocabulary, texture practice, short fabric-swatch readings, listening identification, phrase-frame practice, and guided writing. The central language focus is “It is made of…,” “It feels…,” “It looks…,” “It is good for…,” and “It can be used for…”. Students produce a Fabric Swatch Description Card that supports sewing, design studies, portfolio language, and later work with textiles, sustainability, and collection concepts. The teacher-led session reinforces pronunciation, fabric description, and spoken connection between material qualities and garment use.**
