# Module 1 — Week 3 Detailed Breakdown

## Week 3 title

**Garments and Categories**

## Position in module

|Field|Value|
|---|---|
|Module|Studio English Foundations I|
|Week|3 of 14|
|Student level|A2 English|
|Main university-course connection|Introductory sewing, observation drawing, fashion sketching, early design vocabulary|
|Main ESP function|Naming garments and sorting them into basic fashion categories|
|Main student artifact|“Garment ID Card” for one selected garment|
|App workload|70–90 minutes|
|Teacher-led session|45–60 minutes|

## Week 3 purpose

Week 3 gives students the first large set of garment vocabulary they will reuse throughout the module. Weeks 1 and 2 established identity, course routine, studio tools, and studio actions. Week 3 shifts the focus to the objects fashion students design, draw, sew, describe, and critique: garments.

The week should remain highly visual. Students should work with clean images of common garments, simple product-style descriptions, and short listening clips where a speaker describes a garment and the student identifies it.

The main student output is a short **Garment ID Card**: name of garment, category, color, simple features, and one sentence about use or style.

# Week 3 learning outcomes

|Outcome type|By the end of Week 3, the student can…|
|---|---|
|Garment vocabulary|recognize and name common garments in English|
|Category language|group garments into basic categories: tops, bottoms, dresses, outerwear, accessories|
|Listening|identify a garment from a short spoken description|
|Reading / visual reading|match short garment descriptions to images|
|Writing|write 5–8 simple sentences describing one garment|
|Grammar / phrases|use “This is a…,” “It is…,” “It has…,” “It is for…,” and basic singular/plural forms|
|Feedback routine|revise one sentence using correct article, plural, or noun phrase|
|Teacher session|present one garment image using a simple description frame|

# Main grammar / phrase targets

|Function|Sentence frames|
|---|---|
|Naming a garment|This is a dress. / This is a jacket.|
|Naming a category|It is a top. / It is outerwear.|
|Basic description|It is casual. / It is formal. / It is comfortable.|
|Features|It has long sleeves. / It has buttons. / It has pockets.|
|Color|It is black. / It is blue and white.|
|Use / occasion|It is for work. / It is for cold weather.|
|Preference|I like this garment because it is simple.|
|Plural description|These are jeans. / These are shorts.|

## Language notes for Codex

|Language point|Instructional note|
|---|---|
|a/an|Use “a dress,” “a shirt,” “a jacket,” but “an outfit.”|
|plural-only forms|Treat **pants**, **jeans**, and **shorts** as plural in simple sentences: “These are jeans.”|
|category nouns|“Outerwear” can be uncountable in simple category use: “It is outerwear.”|
|dress vs. skirt|Keep visual distinction clear: dress = one-piece garment; skirt = bottom garment.|
|shirt vs. blouse vs. top|Use simple distinctions: shirt = general upper garment; blouse = usually women’s/fashion upper garment; top = broad category.|

# Activity 6 — Create a Garment ID Card

|Field|Specification|
|---|---|
|Activity purpose|Produce the main Week 3 written artifact|
|Activity type|Guided writing|
|Platform category|`writing`|
|Estimated time|15–25 minutes|
|Submission mode|`text_response`|
|Feedback|hybrid: automated correction suggestions + teacher visibility|
|Target length|60–90 words|
|Required assets|student-selected image from app gallery or uploaded/teacher-provided garment image|
|Student-facing language|Portuguese instructions; English sentence frames|

## Writing prompt

**Portuguese student instruction:**

> Escolha uma peça de roupa da galeria. Escreva um “Garment ID Card” em inglês. Diga que peça é, qual é a categoria, qual é a cor, quais detalhes ela tem e para que ocasião ou clima ela serve.

## Required content

|Required element|Sentence frame|
|---|---|
|garment name|This is a ___. / These are ___.|
|category|It is a top / bottom / dress / jacket / outfit.|
|color|It is ___. / They are ___.|
|features|It has ___. / They have ___.|
|use / occasion|It is for ___. / They are for ___.|
|preference|I like it because ___.|

## Model answer 1 — singular garment

> This is a black jacket. It is outerwear. It has long sleeves, pockets, and a zipper. It is simple and modern. It is good for cold weather. I like this jacket because it is comfortable and easy to wear.

## Model answer 2 — plural garment

> These are blue jeans. They are bottoms. They have pockets and a zipper. They are casual and comfortable. They are good for class and everyday use. I like these jeans because they are simple.

## Feedback targets

|Priority|Feedback focus|
|---|---|
|1|correct garment name|
|2|clear category|
|3|correct use of “This is” vs. “These are”|
|4|correct use of “It has” vs. “They have”|
|5|basic adjective use|
|6|clear and complete sentences|
|7|spelling of garment vocabulary|

# Week 3 course-manual text summary

**Week 3 introduces common garment names and basic garment categories. Students learn to identify tops, bottoms, dresses, one-piece garments, and outerwear through image-based vocabulary practice, short readings, and listening activities. The central language focus is simple garment description: “This is a…,” “These are…,” “It has…,” “They have…,” and “It is for…”. Students produce a short Garment ID Card describing one selected garment by name, category, color, features, and use. The teacher-led session reinforces garment pronunciation, category sorting, and a short oral presentation based on the student’s written artifact.**
